# ULTRON — TUF (Asus A17, RTX 3050 4 GB, Ubuntu 26.04) — pip only, no conda.
#
# Install into a venv on the ext4 root, never on the NTFS volume:
#   python3.14 -m venv ~/venvs/ultron
#   source ~/venvs/ultron/bin/activate
#   pip install -r requirements.txt
#
# Then lock what you actually resolved -- the reproducibility checklist wants exact
# library versions recorded alongside every result:
#   pip freeze > requirements.lock.txt
#
# ---------------------------------------------------------------------------------
# Why plain `pip install torch` and NOT --index-url .../whl/cu128
#
# Verified against the live indexes on 2026-08-17:
#   * PyPI torch 2.13.0 ships cp314 wheels and pins nvidia-cudnn-cu13 -- it IS the
#     CUDA 13 build, matching this box's 595.84 driver (CUDA 13.2 capable).
#   * download.pytorch.org/whl/cu128 only has torch 2.10.0 for cp314 -- older, and
#     built against a CUDA the driver does not need us to target.
# So the runbook's cu128 index URL would install an older torch here for no benefit.
# Ampere sm_86 remains fully supported under CUDA 13.
#
# Python 3.14 is fine for the whole stack, which is why there is no 3.11 here:
#   * torch          cp314 wheels on PyPI and on cu128/cu129/cu130
#   * bitsandbytes   py3-none-manylinux_2_24_x86_64 -- ABI-agnostic, loads .so via ctypes
#   * unsloth        requires_python <3.15,>=3.9
#   * transformers / trl / peft / accelerate / datasets  pure-python wheels, >=3.10
# Ubuntu 26.04's archive has no python3.11/3.12/3.13 at all, so 3.14 is also the only
# interpreter available without a PPA or a standalone build.
# ---------------------------------------------------------------------------------
